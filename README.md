# Project-9 Pandas Analyzer and Data Visualization

### Introduction

The Sales Data Analysis and Visualization is a menu-driven Python program developed to analyze sales data stored in a CSV file. It uses Pandas and NumPy to perform data manipulation and mathematical operations, and Matplotlib to create visualizations.

The program allows users to load a dataset, explore its contents, handle missing values, perform statistical analysis, and generate different types of charts. It also provides options to combine, split, search, sort, filter, and transform DataFrames.

The program continues running until the user selects the *Exit* option.

### Features

- Load sales data from a CSV file.
- Display the first five and last five rows of the dataset.
- Display column names, data types, and basic dataset information.
- Handle missing values by displaying, filling, dropping, or replacing them.
- Perform mathematical operations such as addition, subtraction, multiplication, division, modulus, power, square, square root, and absolute value.
- Combine DataFrames using concatenation or merging.
- Split a dataset based on a selected column and value.
- Search for specific values in the dataset.
- Sort data in ascending or descending order.
- Filter numeric data and categorical values.
- Create pivot tables.
- Re-index DataFrames.
- Calculate group-wise averages using transformation.
- Rename DataFrame columns.
- Generate descriptive statistics, including sum, mean, median, standard deviation, variance, minimum, maximum, percentiles, and correlation.
- Perform group-wise statistical analysis.
- Generate six types of visualizations:
  1. Bar Plot
  2. Line Plot
  3. Scatter Plot
  4. Pie Chart
  5. Histogram
  6. Stack Plot
- Save generated visualizations as image files.
- Validate user input and handle common errors.
- Provide a menu-driven interface for performing multiple operations in one execution.
